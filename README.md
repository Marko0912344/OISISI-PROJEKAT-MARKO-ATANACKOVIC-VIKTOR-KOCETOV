# Sajam knjiga — OISISI projekat

## Opis projekta

Konzolna aplikacija za upravljanje podacima sajma knjiga, izrađena u programskom jeziku C# korišćenjem .NET platforme i Visual Studija.

## Članovi tima i podela rada

**Student 1 — Marko Atanacković**

- Modeli: Posetilac, Kupovina, Izdavač.
- Dodavanje, izmena, brisanje i prikaz posetilaca.
- Dodavanje, izmena, brisanje i prikaz kupovina.
- Dodavanje, izmena, brisanje i prikaz izdavača.
- Povezivanje autora sa izdavačem.
- Postavljanje šefa izdavača.
- Dodavanje i izmena knjiga u konzolnom meniju.

**Student 2 — Viktor Kočetov**

- Modeli i funkcionalnosti iz dodeljenog dela specifikacije, uključujući autora, knjigu i adresu.
- Implementacija sopstvenog sloja za XML čuvanje podataka.

## Struktura projekta

- `SajamKnjiga.Core` — modeli, servisi i čuvanje podataka.
- `SajamKnjiga.Console` — konzolni korisnički interfejs.
- `SajamKnjiga.Test` — testovi.

## Tehnologije

- C#
- .NET
- XML serijalizacija
- Git i GitHub
- Visual Studio

## Napomena

Projekat se razvija u odvojenim Git granama. Integracija rada oba studenta je u toku.
